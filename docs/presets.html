Presets

A preset is a config you start from. Pick one by name and your own settings go on top of it.

Ordnance.Config
return {
	Preset = "Tactical",
}

The four

Standard
The framework defaults, unchanged. This preset exists so "the defaults" is something you can pick by name and copy as a starting point for your own.
Arcade
Point and click. No reserve to manage, generous accuracy, gentle recoil, quick reloads and nothing to learn beyond aim, shoot and reload.
Tactical
Slower and more deliberate. Hip fire is loose, aimed fire is rewarded, recoil has to be controlled, and an early reload keeps the round in the chamber.
Realistic
Everything on. The chamber is tracked, bolts and pumps are worked by hand, a dropped magazine takes its rounds with it, weapons can jam, and there is no crosshair or hitmarker to lean on. Hits are lethal.

What each changes

Every setting a preset touches, beside its default. A dash means the preset leaves it alone. Tuning values multiply every weapon's own numbers, so a preset retunes the whole arsenal without knowing what weapons you have.

Your own

A preset is a ModuleScript in Ordnance.Presets that returns a partial config, exactly like Ordnance.Config. It cannot name another preset, and it cannot set weapon-only fields such as Name or Model.

Presets.Hardcore
--[[
	Hardcore
	Tactical handling, no HUD, and every hit counts double.
]]

return {
	Tuning = { Damage = 2, Recoil = 1.25 },
	Realism = { Chambering = true, DropMagazine = true },
	HUD = { Enabled = false },
}

The first line of the comment block is the name and the paragraph under it is the description; the plugin and the catalogue show both. The plugin's Presets tab can also save your current Ordnance.Config as a new preset, and export or import one as text to share.

Updates add presets that ship with new versions and never touch the ones you made or edited.
